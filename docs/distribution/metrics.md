# Distribution Metrics

Use `docs/measurement-plan.md` as the canonical measurement model. This file narrows it for article distribution issues.

## Snapshot Schedule

- 48 hours: check launch post quality, link preview, discussion quality, and obvious crawl/indexing problems.
- 7 days: record saves, sends, substantive comments, external link visits where available, and Search Console URL inspection status.
- 30 days: record search impressions/clicks, follow-up opportunities, citations, invitations, and whether the article should become a talk, guide, or deeper essay.
