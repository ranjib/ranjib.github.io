# Visual Kit

## LinkedIn Banner

Target: 1584 x 396 px, 4:1 personal profile background image.

Current sizing note: LinkedIn has historically recommended 1584 x 396 px for personal background photos. Recheck LinkedIn upload guidance before a final manual profile update because platform UI and safe areas can change.

Assets:

- Source: `docs/brand/assets/linkedin-banner.svg`
- Export: `docs/brand/assets/linkedin-banner.png`

Design intent:

- Communicate systems thinking across code and the physical world.
- Use restrained site colors and typography.
- Keep key text in the center-right safe area.
- Avoid a collage of every hobby.

Alt text:

> Ranjib Dey LinkedIn banner with Systems in Practice text and abstract lines connecting code, reliability, open-source hardware, field systems, and learning.

## Avatar Guidance

- Use the current public headshot from the site profile image unless Ranjib chooses a newer professional photo.
- Keep the face centered and readable in a circular crop.
- Do not use hobby, family, or location-specific images as the profile avatar.

## Social Card Rules

Shared with `docs/social-metadata.md`:

- Keep Open Graph images at 1200 x 630 px.
- Use the site palette and `Ranjib Dey` master identity.
- Article-specific cards should clarify the topic, not introduce a separate sub-brand.
- Alt text is required for every social-card asset.

## Banner QA

- [ ] Export is 1584 x 396 px.
- [ ] PNG is under 8 MB.
- [ ] Text remains readable when viewed at mobile width.
- [ ] Bottom-left area does not contain important text.
- [ ] Desktop and mobile LinkedIn previews are manually inspected during rollout.
